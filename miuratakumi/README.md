# miuratakumi demo site

## デザインコンセプト

老舗工務店系。既存サイトで強く出ている「匠の技」「棟梁の心」「木の住まい」を、和モダン・木の質感・余白の大きい写真主役の構成に再編集しました。AIっぽい量産LPではなく、地域工務店の手仕事と信頼が伝わる提案用デモを目指しています。

## 営業提案時の見せ方

既存サイトの弱点である固定幅テーブルレイアウト、古い画像ボタン、スマホ非対応感、問い合わせ導線の弱さを、写真主役のファーストビュー、整理されたサービス導線、会社概要、相談フォームデモで改善できることを見せます。実在しない口コミや実績は追加せず、確認できる情報だけで「良くなりそう」と伝えるためのデモです。

## GitHub Pagesへアップロードするときの注意点

`miuratakumi` フォルダをそのまま `demo` リポジトリ直下へアップロードしてください。`.github`、ワークフロー、`.nojekyll`、`robots.txt` は不要です。画像パスは `index.html` から見た相対パス `assets/...jpg` で固定しています。
