# hino-koumuten 提案用デモサイト

このフォルダは、株式会社 檜工務店様の既存ホームページリニューアル提案用サンプルです。公式サイトとして公開するものではありません。

## デザインコンセプト

選定コンセプト: 自然素材・健康住宅系と老舗工務店系の中間。

公式サイトで確認できる「エアサイクルの家」「元気の出る住宅」「昭和55年創業」「大工由来の工務店」という要素を、生成り、深緑、木の質感、明朝系見出し、大きな写真で表現しました。量産LP感を避け、建築雑誌や地域工務店の実サイトに近い静かな印象を目指しています。

## 営業提案時の見せ方

最初にファーストビューを見せ、既存サイトより写真の世界観が強くなることを伝えます。次に、事業内容、強み、施工事例、相談導線が1ページで自然につながることを説明すると、リニューアル後の問い合わせ導線が具体的に伝わります。
