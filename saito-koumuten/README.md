# saito-koumuten

## デザインコンセプト

対象サイトの「自社施工」「職人と直接相談できる」「仙台市を中心に住まいの工事へ対応」という情報をもとに、老舗工務店系の落ち着きと、リフォーム相談のしやすさを合わせた和モダン寄りのデモサイトにしました。写真を主役にし、墨色、生成り、木の色で上質な印象を作っています。
