# takezawakoumuten

株式会社 竹澤工務店様向けの営業提案用サンプルサイトです。公式サイトではありません。

## デザインコンセプト

老舗工務店系。1966年設立、木造建築への知見、一級建築大工技能士の店としての現場感、店舗・医院・寺院まで扱う施工力を、和モダンで落ち着いた住宅会社サイトとして再構成しました。
